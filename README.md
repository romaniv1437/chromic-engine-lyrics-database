# Chromic Engine Lyrics Database

This repository stores the lyrics database used by [chromic engine extensions](https://github.com/romaniv1437/chromic-extension)[](https://github.com/romaniv1437/chromic-haptic).

It is maintained separately so the app and extension can consume versioned lyrics data without bundling the full database into the main application repository.

This repository updates after successful response from [Modal apps](https://modal.com), because I have starter plan there, there is limit of how much tracks lyrics and haptics configs modal allows to generate each month.
If all tracks you test fails - it may be that we run out of modal credits. 
Some tracks are DRM protected and its not possible to generate lyrics/haptics for it.

Anyway, if generated lyrics seems bad, its because this is generated by AI in ~3 minutes per track, this I try to improve with different ways
